# Threat Intelligence — študijná príprava (TIEv1)

Interaktívna študijná stránka a poznámky k desiatim modulom kurzu **Threat Intelligence Essentials (TIEv1)**, pripravené na opakovanie pred písomkou.

## Obsah repozitára

- [`index.html`](index.html) — samostatná študijná stránka: obsah všetkých 10 modulov, porovnania kľúčových pojmov, kontrolné otázky s odpoveďami a preklápacie kartičky pojmov. Stačí otvoriť v prehliadači, nič sa neinštaluje.
- [`poznamky-threat-intelligence.md`](poznamky-threat-intelligence.md) — zdrojové študijné poznámky v Markdowne, z ktorých stránka vychádza.

## Zobrazenie online

Po zapnutí GitHub Pages (Settings → Pages → Deploy from branch → `main` / `/ (root)`) bude stránka dostupná na:

`https://adammacko.github.io/Threat-Intelligence/`

## Poznámka

Pôvodné PDF slidy kurzu TIEv1 (autorský materiál poskytovateľa kurzu) tu zámerne nie sú — repozitár obsahuje len vlastné poznámky a odvodenú študijnú stránku.
